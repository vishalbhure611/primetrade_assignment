# 🧩 Primetrade Assignment

This repository contains both the **Backend (Spring Boot)** and **Frontend (React.js)** implementations for the Primetrade Assignment.

---

## 🚀 Tech Stack

### Backend:
- Java 17
- Spring Boot 3.5.7
- Spring Security (JWT)
- Spring Data JPA (Hibernate)
- MySQL Database

### Frontend:
- React.js
- Axios
- React Router DOM
- CSS Modules
